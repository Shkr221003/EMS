# Employee Management System

A Spring Boot REST API application for managing employee records.

## Features

- Add Employee
- View Employee List
- Update Employee Details
- Delete Employee
- Search Employee by ID

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## API Endpoints

| Method | Endpoint |
|----------|------------|
| POST | /employees |
| GET | /employees |
| GET | /employees/{id} |
| PUT | /employees/{id} |
| DELETE | /employees/{id} |
